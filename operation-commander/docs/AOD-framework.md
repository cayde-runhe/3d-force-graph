# AOD 框架 v1.0 — 智能体导向设计

> Agentic Oriented Design · 作战指挥官智能体的完整认知架构

---

## 一、框架总览

AOD（Agentic Oriented Design，智能体导向设计）是一种面向**自主智能体**的系统架构方法论，强调**意图驱动、闭环反馈、层次递进**的认知流程。

本框架以**作战指挥官**为原型，构建从"接收上级指令"到"输出可执行作战计划"的完整链路。共 **6 大层级、70 个 AOP 节点**。

```
┌─────────────────────────────────────────────────────────────────────┐
│                           AOD 指挥官智能体架构                          │
├──────────────┬──────────────────────────────────────────────────────┤
│  L1 输入理解  │ 上级指示 · 敌情 · 我情 · 战场环境 · 法理授权 · 情报体系          │
│  L2 分析判断  │ 意图推断 · 力量对比 · 节点分析 · 风险评估                       │
│  L3 规划生成  │ 构想开发 · 方案生成 · 方案评估 · 选择确认 · 计划协调              │
│  L4 执行控制  │ 指令分发 · 行动控制 · 协同管理 · 实时监控 · 风险预警              │
│  L5 反馈适应  │ 效果评估 · 差异分析 · 方案调整 · 决策输出                        │
│  L6 复盘优化  │ 行动总结 · 经验提炼 · 改进建议 · 行动结束                        │
└──────────────┴──────────────────────────────────────────────────────┘
```

---

## 二、与 CoT 思维链的对应关系

| CoT 思维链节点 | 对应 AOD 层 | 说明 |
|:---|:---|:---|
| 意图理解 | L1 输入理解 + L2 部分分析判断 | 21 项要素覆盖 L1 全层 + L2 威胁/弱点 |
| 情况判断 | L2 分析判断 | 敌我力量对比、关键节点、风险评估 |
| 形成构想 | L3 规划生成 | 多个行动概念生成 + 评估选择 |
| 制定计划 | L3 规划生成 + L4 部分执行控制 | 详细计划制定 + 协调完善 + 指令下达准备 |
| 仿真推演 | L5 反馈适应（预演） | 虚拟环境中预评估方案效果 |
| 效果评估 | L5 反馈适应 + L6 复盘优化 | 指标评估 + 差异分析 + 经验提炼 |

## 三、完整 AOP 节点清单（70 个）

### L1 输入理解层（Input & Comprehension）— 26 个节点

本层负责**全面接收并理解**来自上级、敌方、我方、环境等一切输入信息，是整个认知链的"感知入口"。

#### L1.1 上级指示理解（7）

| # | AOP 节点 | 英文 | 说明 |
|---|:---|:---|:---|
| 01 | 上级指令接收 | Command Reception | 接收并确认来自上级的作战指令、命令、意图 |
| 02 | 任务性质判定 | Mission Classification | 判断任务类型：进攻/防御/支援/保障 |
| 03 | 任务范围界定 | Mission Scope Definition | 明确任务的空间边界、时间边界、权限边界 |
| 04 | 优先顺序确认 | Priority Confirmation | 确认多个目标间的优先级与主次关系 |
| 05 | 资源限额获取 | Resource Quota Acquisition | 获取允许使用的兵力、装备、弹药、时间限额 |
| 06 | 协同需求解析 | Coordination Requirement Analysis | 解析需要与哪些友邻部队协同及其要求 |
| 07 | 限制条件识别 | Constraint Identification | 识别上级对行动方式、手段、时机的限制 |

#### L1.2 敌情理解（4）

| # | AOP 节点 | 英文 | 说明 |
|---|:---|:---|:---|

| 09 | 敌方装备分析 | Enemy Capability Analysis | 分析敌方主战装备性能、数量、状态 |
| 10 | 敌方企图研判 | Enemy Intention Assessment | 研判敌方作战企图、行动方向、打击目标 |
| 11 | 敌方弱点识别 | Enemy Weakness Identification | 从情报中发现敌方薄弱环节与可利用之处 |

#### L1.3 我情理解（5）

| # | AOP 节点 | 英文 | 说明 |
|---|:---|:---|:---|

| 15 | 我方优势确认 | Own Strength Confirmation | 明确我方相对于敌方的优势领域 |
| 16 | 己方伤亡承受力 | Casualty Tolerance | 确定可承受的最大伤亡水平 |

|---|:---|:---|:---|

### L2 分析判断层（Analysis & Judgment）— 14 个节点

本层在 L1 基础上进行**深度分析**，形成对战场态势的综合判断。

#### L2.1 威胁与力量分析（4）

| # | AOP 节点 | 英文 | 说明 |
|---|:---|:---|:---|
| 27 | 敌我力量对比 | Force Ratio Analysis | 计算敌我双方综合战力比 |
| 28 | 关键节点识别 | Critical Node Identification | 识别战役中的关键节点：指挥所、弹药库、桥梁 |
| 29 | 威胁等级评估 | Threat Level Assessment | 对各威胁源进行等级排序（高/中/低） |
| 30 | 行动窗口计算 | Action Window Calculation | 计算有利行动的时间窗口与持续时长 |

#### L2.2 风险分析（5）

|---|:---|:---|:---|

## 五、关键设计原则

### 5.1 意图驱动（Intent-Driven）

L1 的所有 AOP 节点最终服务于回答一个问题：**"我方要达成什么目的？"**。这与 AOD 的核心方法论一致：一切行动从明确意图开始。

### 5.2 法理贯穿全程

法理不是单独的一个模块，而是从 L1（AOP-21~23）贯穿到 L3（AOP-42~44 方案生成时自动过滤非法手段）再到 L5 效果评估，确保每一步都在法律授权范围内。

### 5.3 敌我关系双向分析

- L1.2 理解敌人（编制、装备、企图、弱点）
- L1.3 认识自己（兵力、能力、限制、优势）
- L2.1 双向对比（敌我力量比、关键节点、行动窗口）

### 5.4 闭环反馈

```
L1→L2→L3 构成"认知规划链"
L4 执行过程中 L5 实时反馈
L5 调整触发 L3 计划修订或 L4 指令变更
L6 最终复盘形成新的 L1 输入（为下一轮行动）
```

### 5.5 打击目标的法理映射

每个打击目标必须满足三重映射：
- **意图层面**（AOP-01~07）：该目标是否服务于上级指令
- **分析层面**（AOP-28 关键节点）：该目标是否具有战役价值
- **法理层面**（AOP-21~23）：该目标是否在交战规则允许范围内
